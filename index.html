How to Play

Simon Game is a memory challenge where you need to remember and repeat a sequence of colors.

  1. Press any key to start the game or click the start button on mobile.
  2. Watch closely as a color button lights up.👀
  3. Repeat the sequence by clicking the same color button.
  4. After each correct round, a new color will be added to the sequence, making it longer and more challenging.
  5. Your goal is to remember and correctly repeat the entire sequence in the same order.
  6. If you make a mistake, the game will end, and you'll need to start over from the beginning.💀

Good luck and see how long you can keep up!✊
